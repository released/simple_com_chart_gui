# Simple COM Chart 使用指南

[English user guide](USER_GUIDE_EN.md)

本指南適用於 Windows 原生 MFC 版。工具用來監看 UART／COM 接收資料、
解析數值與繪圖、保存紀錄，並在使用者明確操作下傳送命令或檔案。
Python 前端有獨立介面，本指南的語系設定以原生 EXE 為準。

## 1. 安裝與啟動

將下列檔案放在同一個可寫入的資料夾：

```text
SimpleComChart.exe
lang_tw.ini
lang_en.ini
```

支援 Windows 10／11 x64，不需要安裝 Python、Qt 或 Visual C++ 執行階段。
USB-UART 橋接器仍須有合適的 Windows 裝置驅動。工具不會代替硬體驅動。

`SimpleComChart.ini` 儲存在 EXE 旁，包含個人連線與介面偏好；請使用可寫入的資料夾。
同一 Windows 工作階段只開啟一個正常執行個體，再次啟動會切回既有視窗。

## 2. 語系與啟動頁籤

預設為**繁體中文**。使用**設定 → 語系（下次啟動套用） → 繁體中文／English**
選擇語系，正常關閉工具後再次啟動即可套用。選擇當下不會重建視窗、重連、傳送資料或清除擷取內容。

語系記錄在個人 INI：

```ini
[UI]
Language=tw
```

`tw` 為繁體中文，`en` 為英文；沒有有效設定時使用繁體中文。
語系檔使用 UTF-8；修改翻譯時保留識別碼與跳脫字元。缺少／無效的語系檔會提示並使用英文備援；
單一缺漏字串保留英文。原始 RX／TX、欄位名稱、別名、檔案格式、協定代碼與部分底層診斷不翻譯；
Windows 自己提供的檔案對話框與系統錯誤依作業系統語系顯示。

**設定 → 啟動頁籤**可選訊息、圖表或四個圖表，下次啟動套用，未設定時使用圖表。
一般點選頁籤不會改變這個啟動偏好。

## 3. 連線與自動恢復

1. 接上橋接器，按「掃描」。
2. 選擇 COM、鮑率、資料位元、同位檢查與停止位元。
3. 按「連線」。成功後記住該裝置與串列設定；下次啟動只還原選擇，不自動開啟 COM。
4. 若失敗，依提示確認其他工具是否占用連接埠、USB 接線、裝置管理員及串列設定。

橋接器意外移除或讀取失敗後，工具會嘗試恢復同一個可辨識裝置，包含 COM 號碼改變的情況。
等待間隔逐漸增加至最多 10 秒。取消或手動中斷可停止恢復。未知／不明確的裝置需要手動選擇；
不會因另一個裝置取得相同 COM 號碼就改連它。恢復不會重送命令，並保留已擷取資料與選擇。

## 4. 三個主頁籤

| 頁籤 | 用途 | 重要行為 |
|---|---|---|
| 訊息 Messages | 原始接收監看 | 不受數值 Include／Exclude 影響，黑底綠字 |
| 圖表 Chart | 多欄位共用座標圖 | 新欄位預設不勾選，Y 軸依可見已選資料自動縮放 |
| 四個圖表 4 Charts | 選取欄位的資料表與四個獨立圖 | 資料表選擇與四個小圖各自獨立 |

選取頁籤以深灰底白字標示。圖表工具的灰色按鈕在執行時短暫變色，連線時 Connect 呈紅色。

## 5. 訊息顯示、搜尋與字型

可切換 ASCII、HEX，以及選項中的 UTF-8／ANSI 顯示。HEX 顯示位元組與偏移；
ASCII 會將不適合顯示的控制／非 ASCII 位元組轉成可見跳脫形式。顯示方式不會改寫原始接收資料。

使用 `−`／`+` 快速調整訊息字型，範圍 8～32 pt，並立即記錄至 INI。
可設定換行、換列、接收時間戳記、ANSI SGR 色彩與輕量 CR／退格／清除行處理；這不是完整終端機模擬。

「自動捲動」追蹤最新資料。關閉後可以檢視舊訊息；「暫停顯示」只停止畫面更新，接收與錄製仍持續。
「清除訊息」不會停止連線或錄製。

按 `Ctrl+F` 開啟搜尋，`F3`／`Shift+F3` 找下一個／上一個。支援文字、區分大小寫與有界 Regex；
`Ctrl+F2` 加入書籤，`F2` 移至下一個。歷史淘汰或重新格式化後，過期的搜尋／書籤位置不能還原。
訊息歷史上限為 256 KiB；歷史到期與輸入遺失分開顯示。

## 6. 數值解析與過濾

預設每個樣本以 LF／CRLF 結束，例如：

```text
fan,duty:920,target:2340,fg_hz:69.1,offset:-2.5,err:11%,cmd:0x3202,cap:105/76/29
```

名稱與數值可用 `:` 或 `=` 分隔；支援正負整數、小數、科學記號、十六進位與 ASCII 單位尾碼。若整行只有一個完整有限數值，會使用固定欄位名稱 `value`，可直接勾選繪圖。通用方括號欄位如 `[P3:76.1803]` 會建立 `P3`；本工具 readable log 的 `[HH:mm:ss.mmm] [RX] ` 是 PC 記錄前綴，不會建立假欄位。
`11%` 的數值為 11；`cap:105/76/29` 產生 `cap[0]`、`cap[1]`、`cap[2]`。
缺漏或無效數值保持空白，不補成零。`[MCFG:0x00,exp:0xD4]` 分別產生 `MCFG=0`、`exp=212`；`[formula],(S7:,-592)` 產生 `[formula].S7=-592`。最終欄位名稱（含群組與陣列後綴）上限為 128 UTF-8 bytes；超限欄位略過、不截斷，可在實驗室診斷查看原因。

Include／Exclude 先處理整行資料，再進行數值解析：

| 設定 | 範例 | 效果 |
|---|---|---|
| Text Include | `fan,` | 保留包含該完整子字串的行，區分大小寫 |
| Regex Include | `fan,\|ac_adc_mv:` | 保留符合任一選項的行 |
| Regex Exclude | `error\|timeout` | 排除符合任一選項的行，優先於 Include |

逗號與分號不會自動拆成多個條件。Include 留白接受全部；Exclude 留白不排除任何行。
「套用」開始新的數值擷取；無效設定保留原本有效設定與資料。Max CH 預設 256，範圍 1～1024。

「套用 parser／數值分包」沿用最後已確認的 line filter，不會套用主畫面尚未確認的 Include／Exclude／Max CH 編輯。儲存失敗時保留目前設定與資料。新的手動連線重設數值時間原點並退出 Snapshot；自動恢復仍延續既有擷取。

**UART → 欄位解析**另支援 CSV／Tab、平面 JSON、有界 Regex 群組及巢狀 JSON Pointer：

```text
ptr:rpm=/fan/rpm,temp=/temps/1
```

輸入 `{"fan":{"rpm":201},"temps":[25,30]}` 可得到 `rpm=201`、`temp=30`。
「預覽」不套用設定；確認後再按「套用解析器」。A／B／離線的 CR、CRLF、自訂 HEX 分隔符號或電腦接收閒置分包，
可在實驗室的「數值輸入分包」設定，原始錄製不受影響。

## 7. 圖表與四個小圖

新欄位預設不勾選，請自行選取或按「全選」。點選欄位表頭可切換名稱排序；搜尋只影響可見欄位。
數值的別名、單位、倍率與偏移可在「欄位顯示」設定，原始數值與匯出不變。

「重新整理」清除圖表滾動樣本；「自動縮放」重新計算範圍；「凍結圖表／即時圖表」暫停／恢復繪圖；
「數值標記」控制最新點的數值標示。這些操作不清除擷取紀錄或原始訊息。
「自動清除圖表」是週期性清除樣本，並非串列接收或 UI 更新頻率；滑鼠停留可查看提示。

可用滾輪縮放、中鍵／Ctrl+左鍵／Space+左鍵平移、A／B 游標、雙擊回到最新位置與固定 Y 範圍。
Y 軸依選取數值自動變動，不固定在空資料時的 0～50。

主圖「時間範圍」和四個小圖的時間欄皆可選 `250 ms`、`500 ms`、`1 s`～`300 s`，
也可直接輸入秒數（例如 `201`、`0.25`），或加上 `ms`／`s` 單位。
按 Enter 或離開欄位套用；有效範圍為 0.25～300 秒，無效輸入保留原設定。
四個小圖各自獨立，時間刻度以秒呈現；短範圍會顯示小數秒。
此設定不改變接收／更新頻率，也不會增加資料取樣率。命名圖表視圖可儲存這些範圍；
已過期的滾動樣本不會因放大時間範圍而恢復。

四個圖表頁的資料表只顯示勾選欄位，Row／Time 保留；最新資料在最下方，缺值留白。
取消「自動捲到最新資料」後可停留在舊列。四個小圖各自選欄位、時間範圍與 Y 軸，預設不選；
選擇會存入 INI，「全部設為不選」同時清除已儲存的小圖選擇。

## 8. 另存新檔與持續錄製

檔名預設使用電腦本機時間到秒，例如 `20261026_143025.log`，可自行修改。

訊息頁的「尋找」旁有三個按鈕：**另存新檔／開始錄製／停止錄製**。
另存新檔只保存目前保留的顯示內容；沒有訊息時會顯示提示，不會建立空檔。
若要持續保存之後收到的資料，請使用開始錄製。錄製時開始按鈕反灰；停止按鈕
在錄製期間可用，正在完成剩餘寫入時兩者都反灰，完成後可再次開始。
控制區下方會顯示已另存檔案及目前／最後錄製 `.log` 的檔名與大小，不顯示路徑。
KB 以 1024 位元組計算；錄製大小是顯示檔名所屬的目前分段，不是 raw 接收量或全部分段總和。
錄製分段檔名會加上 `_1.log`、`_2.log` 等編號；開始錄製仍會產生以下用途的配套檔案。

| 來源 | 格式 | 保存內容 |
|---|---|---|
| 訊息頁另存 | `.log`／`.txt` | 目前格式下全部保留的訊息文字；不是原始二進位 |
| 圖表頁另存 | `.log`／`.txt` | 過濾後的原始資料行 |
| 圖表頁另存 | `.csv`／`.cvs`／`.xls` | 全部保留欄位與資料列，不受可見欄位勾選影響 |
| UART 開始錄製 | `.bin`＋`.idx`＋`.log`＋`.sccmeta` | 持續原始 RX、接收時間／事件、可讀 TX／RX 與安全起始設定 |

另存是確認檔名時的保留資料快照，不包含之後接收的資料；數值擷取上限 10000 行／32 MiB。
XLS 支援 254 個數值欄位加 Row／Time，較寬資料請用 CSV／log。匯出在背景進行，失敗時保留原有目的檔。

持續錄製不受訊息清除、顯示暫停或圖表過濾影響；raw `.bin` 只含 RX。預設鍵值解析除 `key:value`／`key=value` 外，也接受 `[S07],raw:,-19056` 形式並建立 `[S07].raw`；分離的下一個 token 必須是完整有限數值。
使用者可自行選擇可讀 `_1.log`、`_2.log` 等檔案的名稱前綴與資料夾；程式會在 EXE／INI 同層自動建立 `log` 資料夾，集中保存 `.bin`、`.idx` 與相鄰的 `.sccmeta`。若無法建立資料夾或同名檔已存在，錄製會明確失敗且不覆寫舊檔。
「錄製選項」設定輪替大小、每日輪替、輸出總量、秒數上限與最小可用空間；0 表示不啟用該項上限。
達上限只停止錄製，不斷線也不刪舊紀錄。錄製設定於下次 A 或 B 開始錄製時套用。

## 9. 傳送主控台與串列控制

**UART → 傳送主控台／串列選項**提供 UTF-8 文字或 HEX 輸入與 None／CR／LF／CRLF 結尾。
HEX 使用 `41 42` 或 `4142`，不加 `0x`。每次含結尾最多 4096 bytes；按傳送或 `Ctrl+Enter` 才送出。
選取歷史、載入預設命令與預覽不會自動傳送。

可儲存 32 筆歷史與 8 個預設命令。這些個人 INI 資料可能含密碼或私人命令，編碼不代表加密。
流量控制支援 None、RTS/CTS、XON/XOFF、DSR/DTR；手動 DTR／RTS 受握手模式限制。
Break 是明確的約 250 ms 線路訊號，不是 Ctrl+C。控制腳位／Break 可能重設裝置，請確認接線與目標狀態。

每次建立新的有效連線時，鍵盤傳送與本機狀態回顯預設開啟；手動停用會維持到該連線結束。回顯顯示可讀 ASCII，控制字元與非 ASCII bytes 使用跳脫格式，且不會寫成 RX 或加入 raw `.bin`。貼上仍需逐次預覽確認；取消或斷線不會重送已排入或未送出的按鍵。
驅動接受資料與裝置已完成處理是不同狀態。

## 10. 雙 COM 工作台

**UART → 工作台／雙 COM**同時顯示上下兩組。A 使用主視窗連線，B 獨立選取與連線；
兩組接收視窗、控制、傳送、另存與錄製分開，不混在同一個 log 視窗。

工具選單提供分包檢視、二進位數值解析、B 文字圖表、唯讀欄位／位元檢視、命名命令與有限步驟腳本、
傳送節奏、檔案傳輸、唯讀 Modbus RTU、單色終端機子集、儀表與 FFT、XY 及兩次錄製比較。
A／B 轉送需明確確認與數量／時間限制；停止、錯誤、資料缺口或斷線後不會自動恢復。

## 11. 離線重播、設定檔與分析

完成的 raw／index 輪替分段可依接收時間重播；無索引資料使用明確標示的模擬時間。
載入後先暫停，支援播放速度、紀錄／時間定位與跨段文字／HEX 搜尋，不會送到 UART。
大型重播使用背景讀取與分頁索引，上限 64 GiB／5000 萬紀錄／4096 分段，並非相同大小的 RAM 配置。

命名 `.sccprofile` 可保存安全的 A／B 工作設定。載入只暫存，須在斷線閒置且卸載重播後確認套用；
不包含私人命令、歷史、錄製路徑或自動啟動狀態。語系是獨立的個人偏好，不隨工作設定檔覆寫。

圖表分析可檢查游標差、區間 min／max／mean／RMS／標準差與參考線。
衍生欄位支援有界數學式及 EMA；缺值不沿用舊值。FFT 需要有效取樣時間，並非 UART 位元時序量測。

## 12. 實驗室功能

| 頁面 | 用途與操作 |
|---|---|
| 診斷 | 觀察過濾、解析與軟體資料缺口；不代表已證實的線路遺失 |
| 錄製檔／範圍匯出 | 檢查分段、匯出範圍、另存可用前段，不原地修理原檔 |
| 多參數封包 | 命名參數、長度／手動序號、檢查碼、COBS／SLIP；先預覽，再確認傳送一次 |
| 序號／回覆統計 | 觀察序號不連續與最近有限腳本的電腦回覆時間 |
| 離線解析測例 | 匯入／執行／保存有上限的 CSV 測例，不操作 COM |
| 二進位格式／編碼 | 依 Message ID 使用有型別欄位與自訂格式 |
| 數位狀態歷程 | 依回報數值畫位元／列舉狀態，不跨缺口延伸 |
| 錄製工作階段 | 建立相對檔名＋SHA256 清單，驗證後暫存安全設定，不複製 raw |
| COM 裝置資訊 | 唯讀顯示驅動提供的名稱、VID／PID、位置等，不猜測缺漏序號 |
| 數值輸入分包 | 分別設定 A／B／離線的文字結束條件 |
| 自訂 CRC | 設定 CRC8／16／32 參數與範圍，用於共用 TX／RX 核心 |
| 時間微分／積分 | 對保留原始數值離線運算並匯出，缺口與重連切斷區段 |
| 被動請求／回覆分析 | 依 ID 與前綴觀察配對、逾時與不明確重疊，不傳送資料 |

工作階段的 `.sccmeta` 是起始設定快照，不是完整的設定變更歷史；後續數值設定變更會標記。

Session manifest 僅參照同資料夾檔案。若選擇包含 readable `.log`，每一個 `.bin` 分段都必須有同層 `.log`；缺少時會列出清單並停止建立。若 readable log 存在其他資料夾，可明確選 No 建立 raw/index-only Session，該 log 不會包含在 manifest 中。
SHA256 只能檢查檔案內容一致性，不能證明來源身分或裝置功能正確。

## 13. 常見問題

| 現象 | 檢查方式 |
|---|---|
| 連線失敗 | 關閉占用同一 COM 的 Tera Term／PuTTY 等工具，確認 USB、驅動與串列設定 |
| 有文字但沒有圖 | 先確認格式／分包、Include／Exclude、解析預覽，再勾選要顯示的數值欄位 |
| 小值擠在一起 | 使用四個圖表的獨立 Y 軸，或只勾選需要的欄位 |
| 資料更新時畫面跳動 | 關閉自動捲動；暫停顯示時錄製仍可繼續 |
| 舊資料消失 | 查看保留／到期／遺失計數；長時間資料使用持續錄製 |
| 出現英文介面或提示 | 確認語系選擇、重新啟動、兩個語系檔位置與 UTF-8 格式；技術診斷可保留英文 |
| INI 無法儲存 | 使用可寫入資料夾並移除 INI 唯讀屬性 |

## 15. 視圖、測例、註解與分析交付

以下功能位於 **UART → 實驗室／診斷**，使用上方頁面選單切換。

| 頁面／操作 | 使用方式 |
|---|---|
| 命名圖表視圖 | 在主圖勾選欄位、設定四圖與時間／固定 Y 範圍，輸入視圖名稱並儲存；之後暫存命名視圖，再按套用 |
| 多參數封包 → 編輯參數 | 在表格新增、更新或移除名稱／數值／最小值／最大值；確定後只更新封包參數，不傳送 |
| 圖表圖片匯出 | 選主圖或四圖，輸入寬高後另存 PNG；包含目前座標、曲線與最新標示 |
| 離線解析測例 → 使用已選擷取列 | 先在四圖資料表選一列，再複製實際文字到測例，確認預期數值後加入，另按執行測例 |
| 錄製註解 | 選已完成錄製，輸入位元組位移／數量與註解，新增後另存 `.sccnotes`；載入會驗證來源 |
| 設定檔套用 | 套用前以表格檢查目前／待套用差異；選取一列可讀完整值，取消不變更設定 |
| HTML 分析報告 | 每行輸入一個完整欄位名稱，或使用主圖已勾選欄位，指定時間範圍後儲存獨立 HTML |
| FFT 時頻圖 | 選欄位、FFT 樣本數、取樣率、歷史列數及 dB 範圍，按開始；最新歷程在下方 |

命名視圖保存在 EXE 旁的 `views/名稱.sccview`，亦可匯入／匯出。
視圖名稱可用 1～48 個 ASCII 字母、數字、底線或連字號，不能使用 Windows 保留裝置名稱。
只還原顯示選擇與時間／Y 軸範圍，不變更 COM、解析設定或擷取紀錄。請先解除主圖凍結再套用；找不到的欄位
會列出並保持不選，稍後出現也不會自動勾選。新發現欄位仍不自動勾選；使用者原先儲存的四圖選擇
仍依 INI 還原。較早已淘汰的滾動樣本不會復原。

參數表最多 32 列。名稱須唯一，`length`／`sequence` 保留給封包核心；數值必須有限且在上下限內。
編輯完成後仍需先預覽，並以既有「傳送一次」確認送出；表格沒有自動傳送。

PNG 主圖至少 400×300、四圖至少 800×600，每邊最多 4096、總計最多 1600 萬像素。
檔名預設使用本機日期時間到秒。確認檔名後擷取當下圖表，再於背景編碼儲存。
此功能不改變 Snapshot 的凍結用途；未選欄位的小圖會維持空白。

擷取測例只接受保留的文字列，二進位數值的顯示描述不是解析器輸入。B 文字列會依來源標記
排除工具加上的顯示前綴。使用目前測例編輯器的解析設定，不會自動改變即時解析器；預期值先填入
該解析器的觀察結果，必須自行確認或修改，不能視為獨立正確性證明。既有 64 筆／64 KiB、
每筆輸入最多 4096 bytes 的限制仍適用；預期欄位名稱無法包含逗號、冒號或等號。

註解位移從 0 起算，數量可為 0 作位置標記；位置／範圍必須在來源長度內。
最多 256 筆，每筆文字最多 4096 UTF-8 bytes，整份檔案最多 1 MiB。註解檔須儲存在來源檔旁，
使用相對檔名、長度與 SHA256 驗證，不修改錄製內容。若要定位，先在離線重播載入相同檔名、
相同內容的單一來源，再選註解索引；定位會暫停並移至包含該位移的紀錄，須另按播放。
輪替多檔來源不支援這項定位，EOF 標記也不會猜測定位到最後一筆。「清除暫存註解」不刪除檔案。

設定差異只列支援的工作設定，私人歷史與未支援 INI 區段不納入比較。套用仍要求連線／背景工作閒置，
並開始新的擷取；若檢查期間設定改變，須重新檢查。長值在列表可能縮略，選取後可在詳細欄完整閱讀。

HTML 最多八個欄位，時間為包含兩端點的擷取相對秒數，空白結束值表示最新保留資料。
報告包含原始數值統計與靜態 SVG，缺值／連線代次改變會中斷線段；不包含後續接收、完整 raw 或私人命令。
可直接用瀏覽器開啟，不需要網路、JavaScript 或安裝元件；PNG／HTML 寫入失敗會保留原有目的檔。
各檔案頁面的「取消檔案工作」會要求停止目前背景工作；已經完成的儲存不會撤銷。

時頻圖採用 Hann 視窗並移除平均值，FFT 樣本須為 32～4096 的二次方，歷史 1～256 列，
dB 範圍須在 −200～200 內遞增。取樣率 0 要求來源時鐘近似均勻；UART 批次接收常不符合，
只有知道裝置實際取樣率時才手動指定。它不重取樣，也不量測 UART 位元時序。
每秒最多排程兩次背景計算，沒有新樣本不重算；停止或隱藏頁面後不再排程。
缺口、連線代次、頻率軸或設定改變會重設歷史；需要足夠連續樣本後才重新顯示。
