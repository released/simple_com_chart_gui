# Simple COM Chart 使用指南

[English user guide](USER_GUIDE_EN.md)

本指南適用於 Windows 原生 MFC 版。工具用來監看 UART／COM 接收資料、
解析數值與繪圖、保存紀錄，並在使用者明確操作下傳送命令或檔案。
Python 前端有獨立介面，本指南的語系設定以原生 EXE 為準。

## 1. 安裝與啟動

將下列檔案放在同一個可寫入的資料夾：

```text
SimpleComChart.exe
lang_tw.ini
lang_en.ini
```

支援 Windows 10／11 x64，不需要安裝 Python、Qt 或 Visual C++ 執行階段。
USB-UART 橋接器仍須有合適的 Windows 裝置驅動。工具不會代替硬體驅動。

`SimpleComChart.ini` 儲存在 EXE 旁，包含個人連線與介面偏好；請使用可寫入的資料夾。
同一 Windows 工作階段只開啟一個正常執行個體，再次啟動會切回既有視窗。

## 2. 語系與啟動頁籤

預設為**繁體中文**。使用**設定 → 語系（下次啟動套用） → 繁體中文／English**
選擇語系，正常關閉工具後再次啟動即可套用。選擇當下不會重建視窗、重連、傳送資料或清除擷取內容。

語系記錄在個人 INI：

```ini
[UI]
Language=tw
```

`tw` 為繁體中文，`en` 為英文；沒有有效設定時使用繁體中文。
語系檔使用 UTF-8；修改翻譯時保留識別碼與跳脫字元。缺少／無效的語系檔會提示並使用英文備援；
單一缺漏字串保留英文。原始 RX／TX、欄位名稱、別名、檔案格式、協定代碼與部分底層診斷不翻譯；
Windows 自己提供的檔案對話框與系統錯誤依作業系統語系顯示。

**設定 → 啟動頁籤**可選訊息、圖表或四個圖表，下次啟動套用，未設定時使用圖表。
一般點選頁籤不會改變這個啟動偏好。

## 3. 連線與自動恢復

1. 接上橋接器，按「掃描」。
2. 選擇 COM、鮑率、資料位元、同位檢查與停止位元。
3. 按「連線」。成功後記住該裝置與串列設定；下次啟動只還原選擇，不自動開啟 COM。
4. 若失敗，依提示確認其他工具是否占用連接埠、USB 接線、裝置管理員及串列設定。

- 未連線時，掃描會保留仍存在的裝置選擇；INI 中的舊裝置不存在時，改選掃描結果的第一個 COM。
- 掃描成功但沒有可用 COM 時，欄位維持空白；掃描失敗時保留原選擇。
- 預選不會自動連線，也不會取代上次成功連線的設定；成功連線後才儲存。

橋接器意外移除或讀取失敗後，工具會嘗試恢復同一個可辨識裝置，包含 COM 號碼改變的情況。
等待間隔逐漸增加至最多 10 秒。取消或手動中斷可停止恢復。未知／不明確的裝置需要手動選擇；
不會因另一個裝置取得相同 COM 號碼就改連它。恢復不會重送命令，並保留已擷取資料與選擇。

## 4. 主頁籤

| 頁籤 | 用途 | 重要行為 |
|---|---|---|
| 訊息 Messages | 原始接收監看 | 不受數值 Include／Exclude 影響，黑底綠字 |
| 圖表 Chart | 多欄位共用座標圖 | 新欄位預設不勾選，Y 軸依可見已選資料自動縮放 |
| 四個圖表 4 Charts | 選取欄位的資料表與四個獨立圖 | 資料表選擇與四個小圖各自獨立 |
| Modbus | 雙 COM 的唯讀 RTU 輪詢與交易紀錄 | 定義載入不傳送；明確開始後才讀取 |
| LIN | 離線訊框、訊號定義與 LDF 子集分析 | 驗證後明確套用至原有圖表；目前未配置實機轉接器 |

選取頁籤以深灰底白字標示。圖表工具的灰色按鈕在執行時短暫變色，連線時 Connect 呈紅色。

## 5. 訊息顯示、搜尋與字型

可切換 ASCII、HEX，以及選項中的 UTF-8／ANSI 顯示。HEX 顯示位元組與偏移；
ASCII 會將不適合顯示的控制／非 ASCII 位元組轉成可見跳脫形式。顯示方式不會改寫原始接收資料。

使用 `−`／`+` 快速調整訊息字型，範圍 8～32 pt，並立即記錄至 INI。未設定大小時預設 11 pt；INI 已儲存的大小仍優先使用。
可設定換行、換列、接收時間戳記、ANSI SGR 色彩與輕量 CR／退格／清除行處理；這不是完整終端機模擬。

「自動換行」預設開啟，長文字依視窗寬度折行，調整視窗會重新排版；折行不會替匯出內容插入換行字元。
「隱藏文字中的 NUL（0x00）」也預設開啟，避免大量 `\x00` 洗屏；狀態列另顯示累計收到的 NUL 數量與
「可能雜訊」提示。NUL 也可能是合法二進位資料，不能僅憑此認定硬體雜訊。切至 HEX 可完整檢視保留的位元組，
或關閉隱藏選項恢復 `\x00`。文字「另存新檔」遵循此顯示選項；連續 `.bin`／`.idx`／可讀 `.log` 錄製仍保留全部接收內容。
兩項設定保存至 `[Messages] Wrap`／`HideNul`；缺少設定時預設為 `1`，明確的 `0` 會關閉。清除訊息或新連線會重設 NUL 計數。

程式內建預設開啟「簡易終端顯示」與本機傳送回顯；缺少 INI 或個別設定時也會開啟。
INI 已保存的 `[Messages] LightTerminal=0`／`LocalEcho=0` 仍會保持關閉。
簡易終端的 CR 回到行首、LF 才換行，因此 `CR CR LF` 只顯示一次換行。
在「選項 → 時間戳記」選擇電腦本機時間、經過時間或列間差，簡易終端也會顯示：
每列以該列第一個可見位元組的電腦接收時間標記；CR／退格／清行只修改文字，不會擦掉時間前綴。
經過時間從本次訊息接收起算，列間差的第一個保留列為 `+0.000s`。隱藏的 NUL 不會憑空產生時間列；
同一批接收的多列可有相同時間。這些是電腦接收時間，不代表裝置發送時間。
此模式不提供游標來源定位，可在「選項」關閉以恢復原始訊息監看。HEX 與原始錄製位元組保持不變。

「自動捲動」追蹤最新資料。關閉後可以檢視舊訊息；「暫停顯示」只停止畫面更新，接收與錄製仍持續。
「清除訊息」不會停止連線或錄製。

按 `Ctrl+F` 開啟搜尋，`F3`／`Shift+F3` 找下一個／上一個。支援文字、區分大小寫與有界 Regex；
`Ctrl+F2` 加入書籤，`F2` 移至下一個。歷史淘汰或重新格式化後，過期的搜尋／書籤位置不能還原。
訊息歷史上限為 256 KiB；歷史到期與輸入遺失分開顯示。

### 監看工作流程

訊息工作流程另提供以下操作：

- **選項 → 關鍵字標色規則**：每行 `color,word/line,0/1,text`，例如
  `red,line,0,error`。`word` 只標符合的純文字片段，`line` 標整行；`1`
  區分大小寫。顏色為 `red,yellow,cyan,magenta,blue,white,green`，最多 16
  條、每條文字 1～128 字元。後列規則優先，搜尋高亮優先於規則。預覽只
  檢查格式，按套用後保存；清空後套用可取消。規則只影響顯示。標色範圍與
  查找工作量有上限；達限時會提示部分文字未標色，原始接收與錄製仍完整。
- **回到最新**：恢復跟隨並解除顯示暫停。狀態顯示跟隨／瀏覽／暫停，
  以及離開最新之後實際收到的位元組數；歷史淘汰量仍另計。可選的智慧捲動
  預設關閉，開啟後向上捲動會停止跟隨，手動到底部恢復；明確取消勾選的
  自動捲動不會因此重新勾選。接收與錄製持續進行。
- **選項 → 檢視保留的位元組**：使用開啟時的原始 RX 固定快照，輸入
  十進位絕對位移與 1～4096 位元組，再按預覽。訊息 HEX 的位移須先由十六進位換算；
  檢視器初值已填入保留範圍起點。HEX 與 ASCII 並列，另計
  NUL、CR、LF、CR CR LF；控制字元註記限前 128 個，HEX 仍含全部選取範圍。
  終端編輯後的游標文字不會被當作精確原始資料選取。
- **設定 → 訊息／圖表布局**：可在 Chart／4 Charts 下方顯示訊息，選擇
  25%、50%、75% 高度。預設關閉；高度不足時保留目前頁籤完整顯示，增高
  視窗後恢復分割；實際比例受兩側最小可用高度限制。Messages 頁籤仍使用完整區域。
- **設定 → 最近使用項目**：最多 20 個錄製、設定檔、檢視或工作階段參照，
  可加入既有檔案、改顯示名稱、移除或開啟所在資料夾。移除只移除清單參照。
  錄製可同時記住 raw 與使用者選擇的可讀 LOG 位置；開啟資料夾優先使用
  可讀 LOG 的資料夾。暫存後仍須在既有工具明確載入、驗證或套用。
- **設定 → 監看事件**：本次執行最多保留 200 個 A／B 連線、錄製與傳送
  錯誤，5 秒內相同來源與內容合併計次。背景錯誤工作列閃爍預設關閉，可在
  此視窗開啟。事件不會另建 raw 檔，也不會觸發錄製、重新傳送或硬體操作。

標色與智慧捲動存於 `[Messages]`；布局存於 `[UI] MonitorLayout`；最近參照與
閃爍選項存於 `[Monitor]`。事件、新增位元組計數與開啟的檢視器不跨次保留。

## 6. 數值解析與過濾

預設每個樣本以 LF／CRLF 結束，例如：

```text
fan,duty:920,target:2340,fg_hz:69.1,offset:-2.5,err:11%,cmd:0x3202,cap:105/76/29
```

名稱與數值可用 `:` 或 `=` 分隔；支援正負整數、小數、科學記號、十六進位與 ASCII 單位尾碼。若整行只有一個完整有限數值，會使用固定欄位名稱 `value`，可直接勾選繪圖。通用方括號欄位如 `[P3:76.1803]` 會建立 `P3`；本工具 readable log 的 `[HH:mm:ss.mmm] [RX] ` 是 PC 記錄前綴，不會建立假欄位。
`11%` 的數值為 11；`cap:105/76/29` 產生 `cap[0]`、`cap[1]`、`cap[2]`。
缺漏或無效數值保持空白，不補成零。`[MCFG:0x00,exp:0xD4]` 分別產生 `MCFG=0`、`exp=212`；`[formula],(S7:,-592)` 產生 `[formula].S7=-592`。最終欄位名稱（含群組與陣列後綴）上限為 128 UTF-8 bytes；超限欄位略過、不截斷，可在實驗室診斷查看原因。

Include／Exclude 先處理整行資料，再進行數值解析：

| 設定 | 範例 | 效果 |
|---|---|---|
| Text Include | `fan,` | 保留包含該完整子字串的行，區分大小寫 |
| Regex Include | `fan,\|ac_adc_mv:` | 保留符合任一選項的行 |
| Regex Exclude | `error\|timeout` | 排除符合任一選項的行，優先於 Include |

逗號與分號不會自動拆成多個條件。Include 留白接受全部；Exclude 留白不排除任何行。
「套用」開始新的數值擷取；無效設定保留原本有效設定與資料。Max CH 預設 256，範圍 1～1024。

- 通過驗證的過濾設定會先儲存至 INI，再開始新擷取。儲存失敗時保留目前過濾條件、數值資料與 Snapshot 狀態。
- Text 模式的引號是篩選內容的一部分；例如 `"rpm"` 只匹配包含引號的文字。套用、重新啟動及 profile 套用皆保留原字串的引號與空白。
- 啟動時發現無效 Capture 設定，會保留原始 INI 並暫停數值擷取，直到明確套用有效設定。字型與四圖選項的變更不會覆寫該設定區塊。

「套用 parser／數值分包」沿用最後已確認的 line filter，不會套用主畫面尚未確認的 Include／Exclude／Max CH 編輯。儲存失敗時保留目前設定與資料。新的手動連線重設數值時間原點並退出 Snapshot；自動恢復仍延續既有擷取。

**UART → 欄位解析**另支援 CSV／Tab、平面 JSON、有界 Regex 群組及巢狀 JSON Pointer：

```text
ptr:rpm=/fan/rpm,temp=/temps/1
```

輸入 `{"fan":{"rpm":201},"temps":[25,30]}` 可得到 `rpm=201`、`temp=30`。
「預覽」不套用設定；確認後再按「套用解析器」。A／B／離線的 CR、CRLF、自訂 HEX 分隔符號或電腦接收閒置分包，
可在實驗室的「數值輸入分包」設定，原始錄製不受影響。

## 7. 圖表與四個小圖

新欄位預設不勾選，請自行選取或按「全選」。點選欄位表頭可切換名稱排序；搜尋只影響可見欄位。
數值的別名、單位、倍率與偏移可在「欄位顯示」設定，原始數值與匯出不變。

「重新整理」清除圖表滾動樣本；「自動縮放」重新計算範圍；「凍結圖表／即時圖表」暫停／恢復繪圖；
「數值標記」控制最新點的數值標示。這些操作不清除擷取紀錄或原始訊息。
「自動清除圖表」是週期性清除樣本，並非串列接收或 UI 更新頻率；滑鼠停留可查看提示。

可用滾輪縮放、中鍵／Ctrl+左鍵／Space+左鍵平移、A／B 游標、雙擊回到最新位置與固定 Y 範圍。
Y 軸依選取數值自動變動，不固定在空資料時的 0～50。

主圖「時間範圍」和四個小圖的時間欄皆可選 `250 ms`、`500 ms`、`1 s`～`300 s`，
也可直接輸入秒數（例如 `201`、`0.25`），或加上 `ms`／`s` 單位。
按 Enter 或離開欄位套用；有效範圍為 0.25～300 秒，無效輸入保留原設定。
四個小圖各自獨立，時間刻度以秒呈現；短範圍會顯示小數秒。
此設定不改變接收／更新頻率，也不會增加資料取樣率。命名圖表視圖可儲存這些範圍；
已過期的滾動樣本不會因放大時間範圍而恢復。

四個圖表頁的資料表只顯示勾選欄位，Row／Time 保留；最新資料在最下方，缺值留白。
取消「自動捲到最新資料」後可停留在舊列。四個小圖各自選欄位、時間範圍與 Y 軸，預設不選；
選擇會存入 INI，「全部設為不選」同時清除已儲存的小圖選擇。

## 8. 另存新檔與持續錄製

檔名預設使用電腦本機時間到秒，例如 `20261026_143025.log`，可自行修改。

訊息頁的「尋找」旁有三個按鈕：**另存新檔／開始錄製／停止錄製**。
另存新檔只保存目前保留的顯示內容；沒有訊息時會顯示提示，不會建立空檔。
若要持續保存之後收到的資料，請使用開始錄製。錄製時開始按鈕反灰；停止按鈕
在錄製期間可用，正在完成剩餘寫入時兩者都反灰，完成後可再次開始。
控制區下方會顯示已另存檔案及目前／最後錄製 `.log` 的檔名與大小，不顯示路徑。
KB 以 1024 位元組計算；錄製大小是顯示檔名所屬的目前分段，不是 raw 接收量或全部分段總和。
錄製分段檔名會加上 `_1.log`、`_2.log` 等編號；開始錄製仍會產生以下用途的配套檔案。

| 來源 | 格式 | 保存內容 |
|---|---|---|
| 訊息頁另存 | `.log`／`.txt` | 目前格式下全部保留的訊息文字；不是原始二進位 |
| 圖表頁另存 | `.log`／`.txt` | 過濾後的原始資料行 |
| 圖表頁另存 | `.csv`／`.cvs`／`.xls` | 全部保留欄位與資料列，不受可見欄位勾選影響 |
| UART 開始錄製 | `.bin`＋`.idx`＋`.log`＋`.sccmeta` | 持續原始 RX、接收時間／事件、可讀 TX／RX 與安全起始設定 |

另存是確認檔名時的保留資料快照，不包含之後接收的資料；數值擷取上限 10000 行／32 MiB。
XLS 支援 254 個數值欄位加 Row／Time，較寬資料請用 CSV／log。匯出在背景進行，失敗時保留原有目的檔。

持續錄製不受訊息清除、顯示暫停或圖表過濾影響；raw `.bin` 只含 RX。預設鍵值解析除 `key:value`／`key=value` 外，也接受 `[S07],raw:,-19056` 形式並建立 `[S07].raw`；分離的下一個 token 必須是完整有限數值。
使用者可自行選擇可讀 `_1.log`、`_2.log` 等檔案的名稱前綴與資料夾；程式會在 EXE／INI 同層自動建立 `log` 資料夾，集中保存 `.bin`、`.idx` 與相鄰的 `.sccmeta`。若無法建立資料夾或同名檔已存在，錄製會明確失敗且不覆寫舊檔。
「錄製選項」設定輪替大小、每日輪替、輸出總量、秒數上限與最小可用空間；0 表示不啟用該項上限。
達上限只停止錄製，不斷線也不刪舊紀錄。錄製設定於下次 A 或 B 開始錄製時套用。

## 9. 傳送主控台與串列控制

**UART → 傳送主控台／串列選項**提供 UTF-8 文字或 HEX 輸入與 None／CR／LF／CRLF 結尾。
HEX 使用 `41 42` 或 `4142`，不加 `0x`。每次含結尾最多 4096 bytes；按傳送或 `Ctrl+Enter` 才送出。
選取歷史、載入預設命令與預覽不會自動傳送。

可儲存 32 筆歷史與 8 個預設命令。這些個人 INI 資料可能含密碼或私人命令，編碼不代表加密。
流量控制支援 None、RTS/CTS、XON/XOFF、DSR/DTR；手動 DTR／RTS 受握手模式限制。
Break 是明確的約 250 ms 線路訊號，不是 Ctrl+C。控制腳位／Break 可能重設裝置，請確認接線與目標狀態。

每次建立新的有效連線時，鍵盤傳送預設開啟；手動停用會維持到該連線結束。本機狀態回顯缺省開啟，另可在 INI 保存關閉選擇。回顯顯示可讀 ASCII，控制字元與非 ASCII bytes 使用跳脫格式，且不會寫成 RX 或加入 raw `.bin`。貼上仍需逐次預覽確認；取消或斷線不會重送已排入或未送出的按鍵。
在訊息視窗選取文字後按 `Ctrl+C` 會複製，不傳送 UART。沒有選取文字且鍵盤傳送開啟時，`Ctrl+C` 仍傳送 `03`（不是 Break）。持續接收時可先關閉「自動捲動」，再選取複製，避免新訊息將游標移回底部。
驅動接受資料與裝置已完成處理是不同狀態。

## 10. 雙 COM 工作台

**UART → 工作台／雙 COM**同時顯示上下兩組。A 使用主視窗連線，B 獨立選取與連線；
兩組接收視窗、控制、傳送、另存與錄製分開，不混在同一個 log 視窗。

工具選單提供分包檢視、二進位數值解析、B 文字圖表、唯讀欄位／位元檢視、命名命令與有限步驟腳本、
傳送節奏、檔案傳輸、唯讀 Modbus RTU、單色終端機子集、儀表與 FFT、XY 及兩次錄製比較。
A／B 轉送需明確確認與數量／時間限制；停止、錯誤、資料缺口或斷線後不會自動恢復。

## 11. 離線重播、設定檔與分析

完成的 raw／index 輪替分段可依接收時間重播；無索引資料使用明確標示的模擬時間。
載入後先暫停，支援播放速度、紀錄／時間定位與跨段文字／HEX 搜尋，不會送到 UART。
大型重播使用背景讀取與分頁索引，上限 64 GiB／5000 萬紀錄／4096 分段，並非相同大小的 RAM 配置。

命名 `.sccprofile` 可保存安全的 A／B 工作設定。載入只暫存，須在斷線閒置且卸載重播後確認套用；
不包含私人命令、歷史、錄製路徑或自動啟動狀態。語系是獨立的個人偏好，不隨工作設定檔覆寫。

圖表分析可檢查游標差、區間 min／max／mean／RMS／標準差與參考線。
衍生欄位支援有界數學式及 EMA；缺值不沿用舊值。FFT 需要有效取樣時間，並非 UART 位元時序量測。

SHA256 只能檢查檔案內容一致性，不能證明來源身分或裝置功能正確。

## 15. 視圖、測例、註解與分析交付

以下功能位於 **UART → 實驗室／診斷**，使用上方頁面選單切換。

| 頁面／操作 | 使用方式 |
|---|---|
| 命名圖表視圖 | 在主圖勾選欄位、設定四圖與時間／固定 Y 範圍，輸入視圖名稱並儲存；之後暫存命名視圖，再按套用 |
| 多參數封包 → 編輯參數 | 在表格新增、更新或移除名稱／數值／最小值／最大值；確定後只更新封包參數，不傳送 |
| 圖表圖片匯出 | 選主圖或四圖，輸入寬高後另存 PNG；包含目前座標、曲線與最新標示 |
| 離線解析測例 → 使用已選擷取列 | 先在四圖資料表選一列，再複製實際文字到測例，確認預期數值後加入，另按執行測例 |
| 錄製註解 | 選已完成錄製，輸入位元組位移／數量與註解，新增後另存 `.sccnotes`；載入會驗證來源 |
| 設定檔套用 | 套用前以表格檢查目前／待套用差異；選取一列可讀完整值，取消不變更設定 |
| HTML 分析報告 | 每行輸入一個完整欄位名稱，或使用主圖已勾選欄位，指定時間範圍後儲存獨立 HTML |
| FFT 時頻圖 | 選欄位、FFT 樣本數、取樣率、歷史列數及 dB 範圍，按開始；最新歷程在下方 |

命名視圖保存在 EXE 旁的 `views/名稱.sccview`，亦可匯入／匯出。
視圖名稱可用 1～48 個 ASCII 字母、數字、底線或連字號，不能使用 Windows 保留裝置名稱。
只還原顯示選擇與時間／Y 軸範圍，不變更 COM、解析設定或擷取紀錄。請先解除主圖凍結再套用；找不到的欄位
會列出並保持不選，稍後出現也不會自動勾選。新發現欄位仍不自動勾選；使用者原先儲存的四圖選擇
仍依 INI 還原。較早已淘汰的滾動樣本不會復原。

參數表最多 32 列。名稱須唯一，`length`／`sequence` 保留給封包核心；數值必須有限且在上下限內。
編輯完成後仍需先預覽，並以既有「傳送一次」確認送出；表格沒有自動傳送。

PNG 主圖至少 400×300、四圖至少 800×600，每邊最多 4096、總計最多 1600 萬像素。
檔名預設使用本機日期時間到秒。確認檔名後擷取當下圖表，再於背景編碼儲存。
此功能不改變 Snapshot 的凍結用途；未選欄位的小圖會維持空白。

擷取測例只接受保留的文字列，二進位數值的顯示描述不是解析器輸入。B 文字列會依來源標記
排除工具加上的顯示前綴。使用目前測例編輯器的解析設定，不會自動改變即時解析器；預期值先填入
該解析器的觀察結果，必須自行確認或修改，不能視為獨立正確性證明。既有 64 筆／64 KiB、
每筆輸入最多 4096 bytes 的限制仍適用；預期欄位名稱無法包含逗號、冒號或等號。

註解位移從 0 起算，數量可為 0 作位置標記；位置／範圍必須在來源長度內。
最多 256 筆，每筆文字最多 4096 UTF-8 bytes，整份檔案最多 1 MiB。註解檔須儲存在來源檔旁，
使用相對檔名、長度與 SHA256 驗證，不修改錄製內容。若要定位，先在離線重播載入相同檔名、
相同內容的單一來源，再選註解索引；定位會暫停並移至包含該位移的紀錄，須另按播放。
輪替多檔來源不支援這項定位，EOF 標記也不會猜測定位到最後一筆。「清除暫存註解」不刪除檔案。

設定差異只列支援的工作設定，私人歷史與未支援 INI 區段不納入比較。套用仍要求連線／背景工作閒置，
並開始新的擷取；若檢查期間設定改變，須重新檢查。長值在列表可能縮略，選取後可在詳細欄完整閱讀。

HTML 最多八個欄位，時間為包含兩端點的擷取相對秒數，空白結束值表示最新保留資料。
報告包含原始數值統計與靜態 SVG，缺值／連線代次改變會中斷線段；不包含後續接收、完整 raw 或私人命令。
可直接用瀏覽器開啟，不需要網路、JavaScript 或安裝元件；PNG／HTML 寫入失敗會保留原有目的檔。
各檔案頁面的「取消檔案工作」會要求停止目前背景工作；已經完成的儲存不會撤銷。

時頻圖採用 Hann 視窗並移除平均值，FFT 樣本須為 32～4096 的二次方，歷史 1～256 列，
dB 範圍須在 −200～200 內遞增。取樣率 0 要求來源時鐘近似均勻；UART 批次接收常不符合，
只有知道裝置實際取樣率時才手動指定。它不重取樣，也不量測 UART 位元時序。
每秒最多排程兩次背景計算，沒有新樣本不重算；停止或隱藏頁面後不再排程。
缺口、連線代次、頻率軸或設定改變會重設歷史；需要足夠連續樣本後才重新顯示。


## 16. 監看工具

入口為 **設定 > 監看工具**，或以 **Ctrl+Shift+P** 開啟「搜尋功能」。
搜尋器支援本地化功能名稱，僅開啟選取頁面，不會連線、傳送、套用設定、播放或錄製。

- **訊息顯示篩選**：停用簡易終端與 ANSI SGR，選擇 ASCII、UTF-8 或 ANSI。
  包含／排除採區分大小寫文字或圖表有界 Regex，前後文各限 0..10 行。
  比對沿用原始位元組語法，條件以 UTF-8 編碼；ANSI 顯示不會轉換條件的編碼，ANSI 資料可使用 ASCII 條件。
  排除也適用於前後文。篩選僅於本次工作階段有效，不重設數值擷取或改變原始錄製。
  停用後還原保留訊息；另存新檔依目前保留來源與篩選設定產生，顯示暫停時仍然如此。
  切換 HEX 或終端模式前須停用篩選。過長或超出運算上限的行會顯示計數，不截斷後比對。
- **搜尋結果／頻率**：明確搜尋不可變的保留原始文字快照，由背景作業處理。
  最多 4096 筆符合，達上限時會標示，不能視為完整計數。
  超過 65,536 bytes 或超出工作量限制的行會略過；結果與頻率會標示部分搜尋及略過行數，即使沒有符合也不表示完整搜尋。
  可搜尋結果清單並定位原文；已過期、清除、顯示暫停或僅有終端位置時會回報無法定位。
  頻率依 64 個等長電腦接收時間區間計算符合次數，並非封包數或線路時序；合成來源不顯示接收頻率圖。
- **連動時間游標**：預設關閉。四圖保留獨立欄位、時間窗與 Y 軸，只連動時間標記。
  數值須位於設定的最長時差內（預設 0.1 秒），並符合游標來源與連線世代，否則顯示 n/a。
  不插值、不跨來源配對，也不自動變更軸線。可用擷取時間欄位直接指定保留範圍內的游標時間。
- **數值條件監看**：每行格式為 `A/B;精確欄位;下限;上限;遲滯;持續秒數;逾時秒數`。
  最多 16 個來源／欄位組合；下限須小於上限，遲滯不超過半個範圍。
  持續時間為 0..60 秒；逾時大於 0 且不超過 300 秒，不得短於持續時間。
  儲存定義不會啟用；立即啟用須先連線至指定來源，或載入 A 重播。
  無論圖表勾選狀態都會觀察接受的數值，只產生本機監看事件，不觸發傳送或錄製。
  門檻使用原始數值；顯示別名、比例與偏移不改變監看的欄位鍵或數值單位。
  擷取重設、斷線、連線世代改變或已觀察到的輸入／解析佇列遺失時停止對應監看；逾時資料無法取得，不會補零。
  「停止數值監看」會停止全部監看。定義會儲存，啟用狀態不儲存。
- **遮罩 HEX**：在重播的搜尋格式選擇 Masked HEX，輸入 1..256 個空白分隔的位元組或整位元組 `??`，例如 `AA 55 ?? ?? 0D 0A`。
  不接受半位元組萬用字元或 `0x`；既有文字、HEX 與傳送語法維持原樣。
  搜尋可跨讀取與檔案邊界並可取消；找到後暫停於包含該位置的來源紀錄。
- **比較框架**：在工作台二進位檢視器指定兩個快照框架編號及十進位起始偏移。
  編號與偏移僅接受數字組成的整數，不接受科學記號、小數或正負號。
  每份快照最多 4096 bytes。差異清單顯示兩側偏移、位元組、缺少位置與相關解碼欄位。
  僅依指定偏移對齊，不推測插入或刪除。codec 解碼快照使用解碼後偏移；不修改來源或 checksum。
- **錄製索引庫**：搜尋明確索引可取得的名稱、標籤、版本、來源、路徑與檔案修改時間。
  最近項目只作為建議，使用「標籤／儲存索引」後才保留。
  INI 同層的私人 `.scclibrary` 最多保留 1000 項／1 MiB，名稱限 64 字元，標籤限 128 字元。
  缺少的中繼資料維持空白，不會自動驗證雜湊。
  「暫存選取項目」只開啟既有工具供另外檢查、載入或驗證，不會自動播放、套用或連線。
  不遞迴掃描、不複製原始資料、不使用資料庫、不刪除或上傳雲端。外部修改索引庫後須重新開啟。

以上功能使用原生對話框。關閉程式時會取消並等候監看檔案作業結束；已完成的索引儲存不因取消而回復。


## 17. 監看與離線探索

入口位於「設定 → 監看工具」，亦可由 `Ctrl+Shift+P` 搜尋功能名稱。
既有訊息、圖表、四圖表及雙 COM 群組維持原有用途。

- **顯示更新節奏／耗時**：50、100 或 250 ms，預設 50 ms，保存於
  `[Messages] PresentationInterval`。只調整訊息與工作台呈現，不改變接收、
  數值處理限額或原始錄製。字型、排版及明確導覽仍立即更新。
  預覽顯示最近更新、最大更新、樣本經過時間與等候時間；延後繪製另由診斷量測。
  隱藏／暫停時保留舊樣本。較長間隔會增加可見延遲，不能保證排除單次更新過久。
- **A／B 通訊時間線快照**：顯示兩側保留紀錄的 UTC 接收時間、來源、方向、
  世代、序號、長度及前 32 位元組 HEX 預覽。每側最多 2048 筆，總計 512 KiB；
  過期位元組數另列。主連接埠交通歷史不需先開啟工作台即會有界保留。
  兩側依序取得快照，並非同步硬體擷取。同毫秒依 A、B 排序，
  不能據此推定線路順序。結果不隨後續接收改變，也不轉送、錄製或建立永久資料庫。
- **僅觀察**：本次 GUI 工作階段模式，啟動時關閉，不寫入 INI。
  切換前須完成或停止傳送、腳本、轉送、檔案及設定作業。兩側拒絕 TX、控制線、
  Break 及解析器／設定檔套用；重新連線仍保留模式。檢視、複製、縮放、連線／中斷
  及明確啟動 RX 錄製仍可使用。開啟／關閉連接埠本身可能影響硬體腳位，
  因此不是電氣隔離或存取權限機制。解除模式不啟動命令，保留目前連線的手動鍵盤選擇。
- **UTC／ISO 時間**：訊息「選項 → 時間戳記」提供 UTC ISO 8601 及含時區偏移的
  本機 ISO 8601，包含日期與毫秒。顯示與 Save As 使用相同選項；原有時鐘編號及
  預設格式、連續可讀 `.log`、原始 `.bin`／`.idx` 均不變。
  合成時間來源不附加虛構的電腦時間。
- **數值／接收間隔分布**：數值模式選擇來源、原始欄位及包含兩端的擷取相對秒數，
  最多 10000 個保留樣本。顯示 32 區間及最近秩 p50／p95／p99；最後一區包含上界，
  固定值放入第一區，空集合為 n/a。數值可能包含不同世代，不插值。
  接收間隔使用所選埠 RX 讀取區塊的電腦時間（ms），不跨越 TX、世代或序號缺口；
  並非封包週期、線路時間或 MCU 採樣抖動。結果使用背景固定快照。
- **JSON 數值路徑**：離線 UTF-8 樣本最多 64 KiB、深度 16、4096 節點，拒絕重複物件鍵。
  每條路徑最多 512 UTF-8 bytes，路徑總計最多 1 MiB。
  樹狀清單只採用勾選的數值葉節點，最多 64 個。「暫存路徑」產生 `value1`、`value2`
  別名及既有 `ptr:` 定義，處理 `/`、`~`、逗號及引號跳脫，送至解析器設定與樣本預覽。
  名稱與時間欄位仍須檢查；預覽或暫存不會套用解析器或儲存 INI。
- **框架位元組變化**：由 Binary Inspector 開啟，指定從 1 起算的連續 2..256 筆紀錄。
  須等長、同方向、同連線世代，每筆最多 4096 bytes，總計 1 MiB。偏移 0 對齊偏移 0，
  顯示不同數值數量及各位元的相鄰跳變次數。讀取區塊不一定是協定框架；
  codec 快照採解碼後偏移。不自動對齊、修改來源或推定協定欄位。
- **監看警示檢視**：原有七欄規則可追加 `Info`、`Warning` 或 `Critical`，舊規則預設
  `Warning`。保留最近 128 個警示供確認或設定 60 秒後提醒。確認不代表異常解除；
  提醒只在條件仍作用且尚未確認時發出一次本機事件。已解除、淘汰、停止或資料缺口
  解除監看的項目不提醒。定義可保存，警示處理、提醒及監看啟動狀態均不保存，
  不觸發 TX 或錄製。
  列表顯示快照時間；重新整理會更新狀態並保留搜尋與選取的警示 ID。
  選取項目已淘汰時須重新選取，才可執行操作。

顯示成本列出最近更新、最大更新、樣本經過時間與待處理時間，單位為毫秒。
更新耗時不包含延後繪製；隱藏或暫停時保留舊樣本。另存新檔先固定保留資料
與顯示選項，再於背景格式化；後續接收或選項變更不會改變該次匯出。
Port B 設定整批保存；失敗會顯示於該埠狀態，並於五秒後重試，不會重新連線。

## 18. Modbus 與 LIN

### Modbus 唯讀輪詢

1. 在 Modbus 頁籤選取 Port A 或 Port B；「連線設定」開啟既有雙 COM 工作台。
2. 新增／編輯讀取區段，指定站號、功能、位址、型別、順序、倍率與輪詢時間。
3. 預覽確認實際通訊偏移與請求 HEX，儲存定義。此步驟不傳送資料。
4. 連線後按「開始輪詢」。每個連接埠共用工作台的傳送租約，同時最多一筆待回應請求。
5. 在「圖表」勾選欄位，或在「四個圖表」選取訊號。「停止輪詢」保留上次成功值並標示過期。

| 功能 | 位址表示 | 讀取上限 |
| --- | --- | --- |
| FC01 線圈 | 偏移 0 或參考位址 00001 起 | 2000 bits |
| FC02 離散輸入 | 偏移 0 或參考位址 10001 起 | 2000 bits |
| FC03 保持暫存器 | 偏移 0 或參考位址 40001 起 | 125 registers |
| FC04 輸入暫存器 | 偏移 0 或參考位址 30001 起 | 125 registers |

- 位址與站號採十進位；站號為 1..247。參考位址會轉換為通訊偏移，依功能表驗證。
- 每埠最多 32 區段。輪詢與逾時為 100..60000 ms，實際間隔受回應時間及其他區段影響。
- `bit` 讀取單一位元；`u16/i16` 用 1 個暫存器、`u32/i32/f32` 用 2 個、`f64` 用 4 個。
  `raw` 可讀取範圍。順序為 ABCD/CDAB/BADC/DCBA，換算值為原始值 × scale + add。
- 多區段通道包含站號與功能；單區段保留既有 `A.RTU.name`／`B.RTU.name` 命名。
- 開始輪詢建立新的數值擷取；訊息與持續原始錄製維持獨立。輪詢使用電腦接收時間，
  與離線來源、文字時間欄位及同埠其他傳送工具互斥。
- 逾時、例外、部分傳送、連線變更或接收缺口會停止；不自動重試或恢復。
  最後成功值有年齡／過期狀態，不以 0 代替錯誤。
- 交易紀錄保留最近 128 筆，顯示請求／回應 HEX、結果與電腦觀測耗時。
  CRC／長度計數是軟體觀測值，不代表實體線路錯誤量測。
- `.sccmodbus` 是上限 64 KiB 的明確定義檔；載入只暫存，另存固定操作開始時的快照。
  不提供寫入功能、Modbus TCP 或 ASCII。

### LIN 離線紀錄與圖表

1. 載入原生 LIN CSV，或用「輸入 LIN 訊框」建立暫存資料。
2. 載入／編輯 `.scclin` 訊號定義，或載入支援子集的 `.ldf`。
3. 檢查 PID、檢查碼及 Break 資訊。缺少的資訊顯示未知，錯誤訊框不更新圖表。
4. 中斷兩個 COM、卸載重播並完成錄製／檔案工作後，按「套用至圖表」。
5. 切換既有圖表並選取 `LIN.<ID>.<name>`。清除 LIN 檢視可結束此離線圖表來源；暫存定義保留。

原生紀錄使用 UTF-8 CSV，最多 2 MiB／10000 筆，來源秒數須非遞減。
列表顯示最近 4096 筆；完整已載入來源可另存。欄位範例：

```csv
SCC-LIN-TRACE,1
seconds,id,pid,data,checksum,checksum_type,direction,break
0,10,50,05 00,AA,Enhanced,RX,Unknown
0.05,10,,06 00,,Unknown,RX,Unknown
```

- ID/PID/checksum 為 HEX；缺少 PID 或 checksum 留空。資料為 0..8 個完整位元組，空資料表示僅標頭。
- checksum_type 為 Unknown/Classic/Enhanced；direction 為 RX/TX/Unknown；break 為 Unknown/Valid/Invalid。
  PID 同位檢查與檢查碼各自驗證，診斷 ID 3C/3D 採 classic。
- 預設僅 PID 與檢查碼有效的完整訊框進入圖表；Break 未提供時仍顯示未知。
  明確勾選允許未驗證訊框，才接受缺少 PID／檢查碼的來源；已知錯誤永遠排除。
- 檔案不含硬體量測時不推算 Break 或線路時序。來源時間不寫入原始 RX 錄製。
- 圖表以每次最多 64 訊框／約 8 ms 分批匯入；套用固定來源及定義快照。
  後續編輯不改變既有擷取；無可用值時保留原圖表。
- 匯入失敗、取消或過期結果保留原資料；清除後晚到結果不恢復舊來源。
  另存快照不受後續清除影響。

訊號定義上限 64 KiB／256 個訊號，採小端序、1..32 位元、可帶符號及有限倍率／偏移；
同訊框位元範圍不可重疊。範例將資料低 8 bits 換算為 mm：

```csv
SCC-LIN-SIGNALS,1
name,id,start_bit,bits,signed,scale,add,unit
position,10,0,8,0,0.5,0,mm
```

### LDF 子集與硬體限制

- LDF 上限 64 KiB，支援版本 1.3/2.0/2.1/2.2、1000..20000 baud、節點資訊、
  1..32 位元純量訊號與 ID 00..3B 的無條件訊框。
- 支援單一 physical_value 範圍、logical_value 文字及訊號對應；邏輯值保留原始數值供圖表使用。
- 無條件排程最多 16 表、每表 256 槽、總共 1024 槽；時槽為整數毫秒 1..60000。
  主節點發布資料採 LDF 初始值。循環為 1..10000，總時長最多一小時。
- Node_attributes／Node_composition 僅保留來源資訊；事件觸發、零星訊框、診斷執行、
  byte array 及其他關鍵不支援區段會拒絕載入，不宣稱完整 LDF 支援。
- 儲存原始 LDF 保留編碼與排程。儲存手動訊號定義會取代暫存 LDF 範圍、邏輯文字及排程；
  套用前的圖表擷取維持不變。
- 「LIN 介面」顯示實際能力。目前僅離線檔案可用，未提供實機驅動後端；排程可預覽，
  硬體開始按鈕停用。實機需要明確的轉接器／SDK 或已知 MCU 閘道協定及相應驗證。
  一般 UART／RS232 不能直接視為 LIN 實體介面，Windows 計時器不提供 LIN 硬體排程保證。
- 硬體契約要求一個有限排程、世代綁定、取消後等待完成、不自動重試／重連恢復；
  已接受的傳送無法撤銷。此版本未完成實機 LIN 接收或排程驗收。
